# Agent instructions

This repository is a **frontend** project. `predictions-backend` is checked in as **API reference only**.

- Ship all product work in `predictions-frontend/`
- You may **read** Java/DTOs/controllers to learn request/response shapes
- You must **never** modify backend code, config, migrations, or tests
- Missing API fields → frontend fallbacks and/or a note in `docs/proposals/` — not a server change

See `.cursor/rules/frontend-only.mdc` for the same policy with examples.
